# 0.11.8 性能排查记录（2026-09-28）

## 实机证据

- M1 / 8 GB / macOS 26.2；用户确认高占用发生在待机。
- 0.11.7 旧进程连续运行约 14 小时，ps 多次观察为 93.5%–99% CPU。
- 5 秒 sample 的主线程热点为 AppKit 窗口布局、NSHostingView.layout、SwiftUI ScrollView/Form 布局。
- 系统当日上午已有 cpu_resource 报告：179 秒内使用 90 秒 CPU，平均约 50%。
- 替换为 0.11.8 并重启后，短时 ps 观察约 0.3%–1.3%；top 连续两段采样约 1.1% 和 4.4%。不将瞬时百分比解释为耗电比例或长期上限。
- 隔离的静态设置视图测试未重现旧进程持续高占用；修复效果需要在真实设置窗口、听写后与长时间待机继续观察。重启后的占用降低不能单独证明每个代码改动的效果。

## 已执行验证

- `zsh Scripts/package.sh --local-only`：完整 arm64 优化构建及签名校验。
- `SDKROOT=/Library/Developer/CommandLineTools/SDKs/MacOSX26.2.sdk zsh Scripts/test-transport.sh`：双操作端、状态/失败/完成回执、拒绝原因、重建连接后 100 ms 音频包和尾包顺序。
- AudioPipelineSmoke：多种输入分块下音频逐字节一致、尾包仅发送一次、256 KB 上限、5 秒过期、迟到完成回调。
- OverlaySmoke：浮层不激活 App，不成为主窗口或键盘窗口。测试给 RunLoop 增加唤醒计时器，以免静态合成器动画下测试等待远超 0.5 秒而混入用户切换窗口。
